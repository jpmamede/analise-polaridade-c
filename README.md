# Analisador de Polaridade em C

Projeto desenvolvido em C para análise de polaridade de textos.

O programa identifica palavras positivas e negativas em um texto e classifica sua polaridade.

## Conceitos utilizados

- Linguagem C
- Structs
- Ponteiros
- Alocação dinâmica de memória
- Manipulação de strings
- Funções
- Processamento de texto
